# Pouches Spain: vista previa

Página de muestra de la tienda Pouches Spain para el equipo. Los productos son el stock de un posible proveedor; los precios, las cifras y las condiciones son de ejemplo y el carrito no cobra nada. Las fotos de producto y los logos son de cada marca y pertenecen a sus dueños.

Se genera desde la carpeta del proyecto con `node publicar-web.mjs`. No editar los HTML a mano.
