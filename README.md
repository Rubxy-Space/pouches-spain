# Pouches Spain: vista previa

Página de muestra de la tienda Pouches Spain para el equipo, con datos de ejemplo: las marcas son reales, pero los precios, las cifras y las condiciones son inventados y el carrito no cobra nada. Las fotos de producto son las oficiales de cada marca y pertenecen a sus dueños.

Se genera desde la carpeta del proyecto con `node publicar-web.mjs`. No editar los HTML a mano.
